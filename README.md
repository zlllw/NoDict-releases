# NoDict 安装包

**这个仓库只放打包好的安装包，不放源码。**

想用就去 [**Releases**](https://github.com/zlllw/NoDict-releases/releases/latest)
下载最新的 zip。

---

## 这是什么

你在 PDF（四六级真题、外刊、论文都行）里把不认识的词划上高亮，NoDict 把划过
的词一个不落地找出来，在页面右边加一栏，每条写上：

**序号 · 单词 · 音标 · 中文释义 · 这个词在原文那句话里的意思**

原文一个字都不动，出来的还是 PDF，照样打印、照样发。

释义优先查本地词典（ECDICT，63 万词条，离线，不联网）；词典里没有的，
可以用大模型补上句中义。

## 安装（三步，第一次用才做）

1. **装 Python 3.14** —— <https://www.python.org/downloads/>
   安装时**务必勾选** `Add python.exe to PATH`。

   > 必须是 3.14。包里的模块是按 3.14 的 ABI 编译的机器码，装别的版本打不开。
   > 启动器会先把这件事说清楚，不会让你对着一堆 `ImportError` 发呆。

2. **双击 `安装依赖.bat`** —— 装 PyMuPDF 和 Textual，需要联网，约一两分钟。

3. **双击 `启动 NoDict.bat`** —— 界面出来就成了。以后每次用都点这个。

解压到哪都行。如果解压到了 `C:\Program Files` 这类没写权限的地方，程序会
自动把校对成果和输出改存到 `%APPDATA%\NoDict`——**启动时会告诉你改存到哪了**。
